Truth value testing

Any object can be used in a condition. These are all the values that test as false; everything else tests as true, including "0", "False", -1 and [0]. You will also hear these called “falsy” and “truthy” — common jargon, though the official documentation says truth value testing.

ValueKind
FalseThe boolean
NoneThe null object
0   0.0   0j   Decimal(0)Any numeric zero
""   b""Empty text or bytes
()   []   {}   set()   range(0)Any empty collection
objWhose __bool__ returns False or __len__ returns 0
The trap

if not value: is true for an empty list and None and 0. When those mean different things, test with if value is None:.

String methods

Strings are immutable: every one of these returns a new string.

MethodDoesExample
strip / rstrip / lstripRemove leading and trailing characters; whitespace by default" hi ".strip() → 'hi'
removeprefix / removesuffixRemove an exact affix once. 3.9+"a.py".removesuffix(".py") → 'a'
split / rsplitSplit into a list; on any whitespace run if no separator"a,b".split(",") → ['a','b']
splitlines()Split on line boundaries, handling all three endings"a\nb".splitlines() → ['a','b']
join(iterable)Join strings with this one between them", ".join(["a","b"]) → 'a, b'
replace(old, new)Replace occurrences, all unless limited"aa".replace("a","b",1) → 'ba'
startswith / endswithTest an affix; accepts a tuple"a.py".endswith((".py",".pyi")) → True
find / indexPosition of a substring; find gives −1, index raises"abc".find("z") → -1
upper / lower / titleChange case"ab cd".title() → 'Ab Cd'
zfill / center / ljustPad to a width"7".zfill(3) → '007'
isdigit / isalphaTest the whole string; false for """12".isdigit() → True
encode(encoding)Convert to bytes"é".encode("utf-8")

Two handy ones

!r gives the repr, which quotes strings and makes "empty or whitespace?" visible in error messages. A trailing = prints the expression alongside its value, replacing most hand-written debugging prints.

Exception hierarchy

Catching a parent catches its children. This is why except Exception does not catch Ctrl-C — that sits outside it, deliberately.

Built-in exceptions, abridged
BaseException
 ├── SystemExit              # sys.exit()
 ├── KeyboardInterrupt       # Ctrl-C
 └── Exception               # catch THIS, not BaseException
      ├── ArithmeticError
      │    └── ZeroDivisionError
      ├── AttributeError     # obj.missing
      ├── ImportError
      │    └── ModuleNotFoundError
      ├── LookupError
      │    ├── IndexError    # seq[99]
      │    └── KeyError      # d["missing"]
      ├── NameError          # usually a typo
      ├── OSError            # anything the OS refused
      │    ├── FileNotFoundError
      │    ├── PermissionError
      │    ├── TimeoutError
      │    └── ConnectionError
      ├── RuntimeError
      │    └── NotImplementedError
      ├── StopIteration      # next() at the end
      ├── SyntaxError
      │    └── IndentationError
      │         └── TabError # mixed tabs and spaces
      ├── TypeError          # wrong type
      ├── ValueError         # right type, wrong value
      │    └── UnicodeDecodeError
      └── Warning
           └── DeprecationWarning

ExceptionGroup, added in 3.11, carries several exceptions at once — raised by asyncio task groups and caught with except*.

Soft keywords

The last row are keywords only where the grammar expects them, so existing variables with those names still work. That compatibility trick is how pattern matching arrived in 3.10 without breaking code.

Commands

Prefer python -m pip to plain pip: it installs into the interpreter you named.

CommandDoes
python -m venv .venvCreate a virtual environment
source .venv/bin/activateActivate it (macOS, Linux)
.venv\Scripts\activateActivate it (Windows)
python -m pip install requestsInstall a package
python -m pip install -r requirements.txtInstall everything a project needs
python -m pip freeze > requirements.txtRecord exact versions
python -i script.pyRun, then drop into a prompt with its state
python -m http.serverServe the current directory on port 8000
python -m json.tool data.jsonPretty-print and validate JSON
python -m timeit "sum(range(100))"Time a snippet properly
python -m cProfile script.pyFind where the time goes
python -m pdb script.pyRun under the debugger
python -X dev script.pyDevelopment mode: extra warnings
